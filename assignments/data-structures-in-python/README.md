# 📘 Assignment: Data Structures in Python

## 🎯 Objective

Build a small book collection program to practice storing and working with ordered data, key-value relationships, unique values, and fixed records using Python lists, dictionaries, sets, and tuples.

## 📝 Tasks

### 🛠️ Store an Ordered Book Collection

#### Description
Create a collection of books. Represent each book as a tuple containing its title, author, and publication year, and store the tuples in a list.

#### Requirements
Completed program should:

- Create a list containing at least five book tuples
- Display the books in their stored order
- Add a new book and remove a selected book from the list
- Explain why a tuple is suitable for the fixed details of one book and a list is suitable for the changing collection


### 🛠️ Build a Dictionary for Book Lookups

#### Description
Create a dictionary that lets a user look up a book by its title. Each dictionary value should contain that book's author and publication year.

#### Requirements
Completed program should:

- Use book titles as dictionary keys
- Add, update, and retrieve book details by title
- Display a helpful message when a requested title is not in the dictionary
- Print the total number of books stored in the dictionary


### 🛠️ Find Unique and Shared Genres with Sets

#### Description
Give each reader a collection of favorite book genres. Use sets to find genres without duplicates, genres shared by all readers, and genres liked by at least one reader. Summarize the results using the book collection or dictionary from the earlier tasks.

#### Requirements
Completed program should:

- Create a set of genres for at least two readers, including a repeated genre
- Use set operations to display the genres shared by both readers and all distinct genres they like
- Add a new genre and remove a genre from a reader's set
- Include a short output summary showing how lists, tuples, dictionaries, and sets each help organize the program's data
